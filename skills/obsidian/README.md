|---|---|
| `obsidian-markdown` | the page syntax of the `llm_wiki/` vault: wikilinks, embeds, callouts, properties |
| `obsidian-bases` | `.base` views over the vault: open topics, status, confidence |
| `json-canvas` | `.canvas` maps of concepts and connections |
| `obsidian-cli` | drive a running Obsidian vault from the agent |
| `defuddle` | clean markdown from a web page before it goes into `llm_wiki/raw/` |
| `knap` | render markdown templates from JSON or CSV |
